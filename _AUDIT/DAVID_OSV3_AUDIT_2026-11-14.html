Set the owners before moving the folders

November 14, 2026 · combine/fis-into-david-os · 4e36a9a · Already up to date. · git pull exit code: 0

Overall health: strong tools and useful evidence, but no single first-pass owner or consistent handoff between registry, classification and approval. The reviewed judgments below are VERIFIED by code, observed fixtures or hash comparison. Runtime behavior was not tested.

137,116file paths56top-level folders8structural findings13proposed moves
  1. Competing owners for FIS Standalone fis/ owns a full local tag → classify → propose → approval/HTML loop. The legacy folder memory, Tk scanner and paper registry have different outputs. They cannot all be the first-pass owner.
  2. SQLite and identity can split Stage 1 registry.sqlite, engine filebrain.sqlite, standalone index.sqlite and Folder Hub relay.sqlite are separate. The direct JSON/CSV producers do not all first admit proposals to a per-drive registry.
  3. The classification stages do not compose The MIM YAML reviewer, Rust lexicon, standalone FIS checks and deep-identify record different schemas. APOL can use local MiniLM and DeepSeek triage exists separately; these are not proof of a common local-first escalation policy.
  4. Public IDs need an authority gate The registry can propose an S code from four hash characters, including letters. It also creates UUIDv4 version tokens internally. Nothing in that code proves a candidate is an issued numeric S####, or that internal tokens belong in filenames.
  5. Prediction ownership is duplicated 03_CLASSIFY ships a harness; engine/preference and fis/preference contain naming learners; Prediction_GUI owns an independent runner, ledger and approvals. Rename-acceptance and next-event confidence are different targets.
  6. A move can silently break the current HTML Prediction_GUI serves FIS PICS HTML/simple.html by path. Its older guided actions still name localhost:61845; standalone FIS uses its own web boundary. Preserve the wrapper when changing either path.
  7. Resident mechanisms are not one system Installed CLI exposes watch/poll; separate hub and tagger watchers exist. October acceptance documents a sign-in installation. That receipt does not establish current appointment for every resident.
  8. Generated state is mixed into source The tracked GUI catalog and rename feed exceed 5 MB; a 6.98 GB match CSV sits under stage 10 and run trees contain recovery evidence. Moving them without mapping readers can break review and rollback.

Three changes first: name the standalone FIS owner; make per-drive SQLite and identity issuance explicit; let Prediction_GUI own predictions and approvals through stable adapters.
