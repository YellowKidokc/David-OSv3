# Folder Profile Doorway + Pre-Flight Gate — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the two missing FIS pieces: a `01_PROFILE` wizard that profiles folders via the 20-question onboarding flow, and `engine/gate.py`, a pre-flight gate every file action passes through — with the user, not the gate, as final authority.

**Architecture:** Rule knowledge lives in versioned JSON under `config/rules/` (imported from the FIS grammar workbook). `engine/gate.py` is a pure-stdlib evaluator: `evaluate(action_id, target_paths, context) -> Decision` with verdicts ALLOW / PREVIEW / ASK / BLOCK / DROP and a `fired_rules` list. The wizard (`01_PROFILE/`) has a headless core (`profile_core.py`, fully tested) plus a thin PySide6 GUI. User overrides go to the JSONL ledger and become prediction-harness events so engines learn per-folder approval patterns.

**Tech Stack:** Python ≥3.11 stdlib (gate, core, adapter), PySide6 (wizard GUI — same as `gui/operations_panel.py`), pytest, the vendored prediction harness at `03_CLASSIFY/02_CLASSIFICATION/harness/`.

**Spec:** `docs/specs/2026-10-15-folder-profile-doorway-design.md`

## Global Constraints

- Python ≥ 3.11 (repo `pyproject.toml` floor).
- `engine/gate.py`, `profile_core.py`, and `gate_events.py` are **stdlib-only** — no third-party imports (Rust-portability discipline, spec §8).
- Gate decisions are plain JSON-shaped data (dicts/lists/strings/numbers) with a stable shape: `{"verdict", "fired_rules", "required_guardrails"}`.
- Engine-internal imports are flat sibling imports (`import config`, `import ledger`) — match `engine/inventory_scan.py`.
- Fail closed: missing/corrupt rules or missing profile → everything becomes ASK, with a loud error surfaced (never a silent allow).
- `BLOCK` is reserved for never-negotiables (system folders, secrets). Everything else that fails a rule is `ASK` with user override options — the gate is never the final authority.
- No new pip dependencies anywhere in this plan (PySide6 already used by `gui/operations_panel.py`; wizard reuses the repo's existing PySide6 install).
- Commits land in the David-OSv3 repo. Commit message style: short imperative (`gate: add GR-004 secrets block`).

## Review Focus

1. **Folder with no profile** (e.g. a fresh NAS share): a reasonable person expects scan/report to proceed but every mutation to require approval — covered by Task 3 fail-closed tests.
2. **Windows case-insensitive paths** (`D:\GitHub` profile vs `d:\github\...\file.py`): longest-prefix match must not miss — test added to Task 2.
3. **`.env` inside a rename batch**: must hard-BLOCK the whole batch regardless of user overrides — test in Task 3 and Task 5.
4. **Wizard closed mid-run** (user hits X on question 12): nothing may be written — test in Task 6.
5. **Corrupt `folder_profiles.json`** (truncated JSON): gate must degrade to ASK-everything with a visible error, not crash the rename GUI — test in Task 3, wiring in Task 5.

```python
# scripts/import_grammar_workbook.py
"""One-shot importer: grammar workbook dump -> config/rules/*.json.

Reads the tab-separated dump (grammar.txt) and writes the four rule JSONs.
Idempotent; safe to re-run. Stdlib only.
"""
from __future__ import annotations
import json
import sys
from pathlib import Path

REPO = Path(__file__).resolve().parents[1]
DUMP = Path(r"C:\Users\David\AppData\Local\Temp\fisxlsx\grammar.txt")
OUT = REPO / "config" / "rules"

SHEETS = {  # sheet name -> (output filename, schema id, id column)
    "Guardrails": ("guardrails.v1.json", "top-ai-fis.guardrails.v1", "guardrail_id"),
    "Actions_Master": ("actions_master.v1.json", "top-ai-fis.actions_master.v1", "action_id"),
    "Action_Conditions": ("action_conditions.v1.json", "top-ai-fis.action_conditions.v1", None),
    "Compatibility_Matrix": ("compatibility_matrix.v1.json", "top-ai-fis.compatibility_matrix.v1", None),
}

def sheet_rows(text: str, sheet: str) -> list[list[str]]:
    marker = f"########## SHEET: {sheet} "
    start = text.index(marker)
    end = text.find("########## SHEET:", start + len(marker))
    block = text[start:end if end > 0 else len(text)]
    rows = [ln.split("\t") for ln in block.splitlines()[1:] if ln.strip()]
    return rows

def keyed(rows: list[list[str]]) -> list[dict]:
    header = [h.strip().lower().replace(" ", "_").replace("/", "_") for h in rows[0]]
    out = []
    for r in rows[1:]:
        rec = {header[i]: (r[i].strip() if i < len(r) else "") for i in range(len(header))}
        if any(rec.values()):
            out.append(rec)
    return out

def main() -> int:
    text = DUMP.read_text(encoding="utf-8")
    for sheet, (fname, schema, _idcol) in SHEETS.items():
        recs = keyed(sheet_rows(text, sheet))
        assert recs, f"no rows parsed for {sheet}"
        (OUT / fname).write_text(
            json.dumps({"schema": schema, "source_workbook": "FIS_Rule_Automation_Grammar.xlsx",
                        "records": recs}, indent=1, ensure_ascii=False) + "\n",
            encoding="utf-8")
        print(f"[RULES] {fname}: {len(recs)} records", flush=True)
    return 0

if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
"""gate.py — pre-flight action gate.

Every file action (rename/move/archive/delete_later/...) is evaluated against the
rule stack BEFORE it runs: relevance -> guardrails -> folder profile -> action
conditions -> review-gate thresholds -> approval floor. The gate is never the final
authority: anything short of a hard safety stop returns ASK with the fired rules,
and the caller routes that to the user (approve once / always here / reject).

Pure stdlib. No I/O after construction. Decisions are plain JSON-shaped data so a
future Rust port can be differentially tested against this oracle (spec §8).
"""
from __future__ import annotations

import json
from dataclasses import dataclass, field
from pathlib import Path

ALLOW, PREVIEW, ASK, BLOCK, DROP = "allow", "preview", "ask", "block", "drop"
_RANK = {ALLOW: 0, PREVIEW: 1, ASK: 2, BLOCK: 3}

MUTATING = {"rename", "move", "archive", "delete_later", "dedupe", "overwrite",
            "change_extension", "publish"}

SECRET_NAMES = {".env", ".env.local", ".env.production", ".env.development",
                "id_rsa", "id_ed25519", "id_dsa", "credentials.json", "key.txt"}
SECRET_SUFFIXES = (".pem", ".key", ".pfx", ".p12")
PROJECT_MARKERS = {"package.json", "pyproject.toml", "requirements.txt", "cargo.toml",
                   "pom.xml", "build.gradle", ".git", ".gitignore", "node_modules"}
SYSTEM_PREFIXES = ("c:\\windows", "c:\\program files", "c:\\program files (x86)",
                   "/c/windows", "/etc", "/usr", "/bin", "/sbin")

_RULE_JSONS = ("guardrails.v1.json", "actions_master.v1.json",
               "action_conditions.v1.json", "compatibility_matrix.v1.json",
               "review_gates.28pof.v1.json")


@dataclass
class Decision:
    verdict: str
    fired_rules: list[dict] = field(default_factory=list)   # [{"rule_id","reason"}]
    required_guardrails: list[str] = field(default_factory=list)

    def to_json(self) -> dict:
        return {"verdict": self.verdict, "fired_rules": self.fired_rules,
                "required_guardrails": self.required_guardrails}


def _norm(p: str) -> str:
    return str(p).replace("/", "\\").lower()


def _is_system(p: str) -> bool:
    n = _norm(p)
    return any(n.startswith(s) for s in SYSTEM_PREFIXES)


def _is_secret(p: str) -> bool:
    name = Path(str(p)).name.lower()
    return name in SECRET_NAMES or name.endswith(SECRET_SUFFIXES)


def _is_project_file(p: str) -> bool:
    return Path(str(p)).name.lower() in PROJECT_MARKERS


def _threshold_number(text: str) -> tuple[str, float] | None:
    # ">20 files" -> (">", 20.0); "Any count" -> (">", 0.0)
    import re
    m = re.search(r"(>=|>)\s*(\d+)", text or "")
    if m:
        return m.group(1), float(m.group(2))
    if text and "any" in text.lower():
        return ">", 0.0
    return None


class Gate:
    def __init__(self, rules: dict, profile: dict, load_error: str | None = None):
        self.rules = rules
        self.profile = profile or {}
        self.load_error = load_error

    @classmethod
    def load(cls, rules_dir, profile) -> "Gate":
        rules: dict = {}
        try:
            for name in _RULE_JSONS:
                p = Path(rules_dir) / name
                rules[name] = json.loads(p.read_text(encoding="utf-8")) if p.exists() else None
            missing = [n for n in _RULE_JSONS if rules[n] is None]
            err = f"missing rule files: {', '.join(missing)}" if missing else None
        except (OSError, json.JSONDecodeError) as e:
            return cls({}, profile, load_error=f"rule load error: {e}")
        return cls(rules, profile, load_error=err)

    # -- individual checks, each returns Decision | None --------------------

    def _relevance(self, action_id: str) -> Decision | None:
        if action_id in self.profile.get("irrelevant_actions", ()):  # profile says N/A here
            return Decision(DROP, [{"rule_id": "profile.irrelevant_actions",
                                    "reason": f"{action_id} is not applicable in this folder"}])
        return None

    def _hard_safety(self, paths: list[str]) -> Decision | None:
        if any(_is_system(p) for p in paths):
            return Decision(BLOCK, [{"rule_id": "GR-001", "reason": "system folder — never touch"}],
                            ["GR-001"])
        if any(_is_secret(p) for p in paths):
            return Decision(BLOCK, [{"rule_id": "GR-004", "reason": "secrets/config file in batch"}],
                            ["GR-004"])
        return None

    def _guardrail_asks(self, action_id: str, paths: list[str], ctx: dict) -> Decision | None:
        fired = []
        if action_id in MUTATING and any(_is_project_file(p) for p in paths):
            fired.append({"rule_id": "GR-003", "reason": "project root marker in batch"})
        conf = ctx.get("confidence")
        if conf is not None and conf < float(ctx.get("review_threshold", 0.75)):
            fired.append({"rule_id": "GR-007",
                          "reason": f"confidence {conf:.2f} below review threshold"})
        if fired:
            return Decision(ASK, fired, [f["rule_id"] for f in fired])
        return None

    def _profile_rules(self, action_id: str) -> Decision | None:
        if action_id in self.profile.get("blocked_actions", ()):
            return Decision(ASK, [{"rule_id": "profile.blocked_actions",
                                   "reason": f"folder profile blocks '{action_id}' — user may override"}])
        return None

    def _action_conditions(self, action_id: str, ctx: dict) -> Decision | None:
        ac = (self.rules.get("action_conditions.v1.json") or {}).get("records", [])
        row = next((r for r in ac if r.get("action") == action_id), None)
        if not row:
            return None
        fired = []
        blocked_if = (row.get("blocked_if") or "").lower()
        if "protected" in blocked_if and ctx.get("protected"):
            fired.append({"rule_id": f"action_conditions:{action_id}",
                          "reason": "target is protected"})
        if "collision" in blocked_if and ctx.get("collision"):
            fired.append({"rule_id": f"action_conditions:{action_id}",
                          "reason": "filename collision"})
        if "project_root" in blocked_if and ctx.get("project_root"):
            fired.append({"rule_id": f"action_conditions:{action_id}",
                          "reason": "project root"})
        if fired:
            return Decision(ASK, fired)
        return None

    def _review_gates(self, action_id: str, ctx: dict) -> Decision | None:
        gates = (self.rules.get("review_gates.28pof.v1.json") or {}).get("records", [])
        trigger_key = {"rename": "rename_apply batch", "move": "route_apply batch",
                       "archive": "archive_apply batch", "delete_later": "delete candidate"}
        trig = trigger_key.get(action_id)
        if not trig:
            return None
        row = next((r for r in gates if r.get("trigger") == trig), None)
        if not row:
            return None
        tn = _threshold_number(row.get("default_threshold", ""))
        if tn and ctx.get("batch_size", 1) > tn[1]:
            return Decision(ASK, [{"rule_id": f"review_gate:{row.get('gate', trig)}",
                                   "reason": f"bulk {action_id}: batch {ctx.get('batch_size', 1)} "
                                             f"exceeds threshold '{row.get('default_threshold')}'"}])
        return None

    def _approval_floor(self, action_id: str) -> Decision | None:
        floor = self.profile.get("approval_floor") or "preview_only"
        if action_id in MUTATING and floor in ("approval_required",):
            return Decision(ASK, [{"rule_id": "profile.approval_floor",
                                   "reason": f"profile requires approval for mutations ({floor})"}])
        if action_id in MUTATING and floor in ("preview_only", "suggest_only"):
            return Decision(PREVIEW, [{"rule_id": "profile.approval_floor",
                                       "reason": f"profile floor is {floor}"}])
        return None

    # -- the stack -----------------------------------------------------------

    def evaluate(self, action_id: str, target_paths, context: dict | None = None) -> Decision:
        ctx = dict(context or {})
        paths = [str(p) for p in target_paths]
        ctx.setdefault("batch_size", len(paths))

        if self.load_error:  # fail closed
            return Decision(ASK, [{"rule_id": "gate.load_error",
                                   "reason": f"load error: {self.load_error} — everything needs approval"}])

        if action_id not in MUTATING:
            return Decision(ALLOW)  # scan/hash/classify/report are always safe

        d = self._relevance(action_id)
        if d:
            return d
        d = self._hard_safety(paths)
        if d:
            return d  # BLOCK — never negotiable

        best = Decision(ALLOW)
        for check in (self._guardrail_asks(action_id, paths, ctx),
                      self._profile_rules(action_id),
                      self._action_conditions(action_id, ctx),
                      self._review_gates(action_id, ctx),
                      self._approval_floor(action_id)):
            if check is None:
                continue
            if _RANK[check.verdict] > _RANK[best.verdict]:
                best = Decision(check.verdict, [], [])
            if check.verdict == best.verdict:
                best.fired_rules.extend(check.fired_rules)
                best.required_guardrails.extend(check.required_guardrails)
        return best
```

```python
# 03_CLASSIFY/02_CLASSIFICATION/harness/adapters/gate_events.py
"""gate_events — turns gate override ledger rows into harness Events.

The gate is never the final authority: every ASK the user answers is a ruling,
and rulings are what the engines learn from. Re-runs never double-count —
ids are content hashes.
"""
from __future__ import annotations

import hashlib
import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[2]))  # 02_CLASSIFICATION
from harness.contract import Event  # noqa: E402

WATCHED = ("gate_override", "gate_decision")


def _row_to_event(row: dict) -> Event | None:
    if row.get("event") not in WATCHED:
        return None
    folder = row.get("folder") or str(Path(row.get("path", ".")).parent)
    raw = json.dumps(row, sort_keys=True)
    return Event(
        subject=folder,
        action="gate:" + row["event"].removeprefix("gate_"),
        context={"action_id": row.get("action_id", ""), "verdict": row.get("verdict", ""),
                 "choice": row.get("choice", "")},
        source="gate",
        timestamp=row.get("ts", ""),
        id="go-" + hashlib.sha1(raw.encode("utf-8")).hexdigest()[:12],
    )


def read(ledger_path: str | Path) -> list[Event]:
    p = Path(ledger_path)
    if not p.exists():
        return []
    out = []
    for line in p.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line:
            continue
        try:
            ev = _row_to_event(json.loads(line))
        except json.JSONDecodeError:
            continue  # skip torn writes, never die on the ledger
        if ev:
            out.append(ev)
    return out


if __name__ == "__main__":
    from harness.runner import Runner
    repo = Path(__file__).resolve().parents[4]  # David-OSv3
    evs = read(repo / "system" / "ledger" / "file_events.jsonl")
    n = Runner(db_path=Path(__file__).resolve().parents[1] / "data" / "gate.db",
               context_keys=("action_id",)).ingest(evs)
    print(f"ingested {n} gate events")
```

```python
#!/usr/bin/env python3
"""profile_core — headless heart of the 01_PROFILE wizard.

Pure stdlib. Everything except write_profile is a pure function, so the GUI stays
thin and the Rust port can mirror it. write_profile is the ONLY disk write, called
once, when the user confirms.
"""
from __future__ import annotations

import datetime as dt
import json
from collections import Counter
from pathlib import Path

QUESTIONNAIRE = "onboarding_questions.v1.json"
MARKER = ".folder.fmeta"

# questions the user always sees, no matter how confident the suggestion
ALWAYS_SHOW = {"do_not_touch", "important_files", "sensitive_classes",
               "public_private_boundary", "automation_comfort", "allowed_roots_first"}

PROJECT_MARKERS = {".git", "pyproject.toml", "package.json", "cargo.toml", "requirements.txt"}


def load_questionnaire(path) -> dict:
    return json.loads(Path(path).read_text(encoding="utf-8"))


def scan_evidence(root) -> dict:
    """Read-only look at a folder. Returns plain JSON-shaped facts."""
    root = Path(root)
    names = {p.name.lower() for p in root.iterdir()} if root.is_dir() else set()
    exts = Counter(p.suffix.lower() for p in root.rglob("*") if p.is_file())
    return {
        "has_obsidian": ".obsidian" in names,
        "has_project_markers": bool(names & PROJECT_MARKERS),
        "has_api_records": any(p.is_dir() and p.name == "_API" for p in root.iterdir()) if root.is_dir() else False,
        "top_extensions": exts.most_common(8),
        "file_count": sum(exts.values()),
    }


def suggest_answers(questionnaire: dict, evidence: dict) -> dict:
    """question_id -> {"value": ..., "confidence": 0..1, "source": "evidence"|"default"}"""
    out: dict = {}
    for q in questionnaire.get("core_questions", []):
        qid = q["id"]
        if q.get("default") is not None:
            out[qid] = {"value": q["default"], "confidence": 0.5, "source": "default"}
    if evidence.get("has_obsidian"):
        out.setdefault("primary_domains", {})["value"] = ["research"]
        out["primary_domains"].update(confidence=0.8, source="evidence")
    if evidence.get("has_project_markers"):
        out["project_roots"] = {"value": ["this folder"], "confidence": 0.9, "source": "evidence"}
    if evidence.get("has_api_records"):
        out["primary_domains"] = {"value": ["research"], "confidence": 0.7, "source": "evidence"}
    return out


def build_profile(root, answers: dict, questionnaire: dict) -> dict:
    """Map questionnaire answers onto folder_profiles.json fields (Task 2 shape)."""
    env = answers.get("environment_type", "mixed")
    comfort = answers.get("automation_comfort", "require_approval")
    floor = {"report_only": "preview_only", "suggest_actions": "suggest_only",
             "require_approval": "approval_required"}.get(comfort, "approval_required")
    profile = {
        "path": str(root),
        "folder_role": env,
        "review_only": floor != "auto_after_threshold",
        "protected": bool(answers.get("sensitive_classes")),
        "approval_floor": floor,
        "thresholds": {"auto_approve_rename_confidence": 0.98},
        "routing_hints": {},
        "parser_preferences": ["deterministic"],
    }
    if answers.get("do_not_touch"):
        profile["blocked_actions"] = ["delete", "move", "rename", "archive"]
    return profile


def write_profile(root, profile: dict, profiles_path, answers: dict, evidence: dict) -> None:
    """The only writer. Appends/updates the registry entry; writes the marker unless
    the folder is a project root (marker contract: never write inside those)."""
    root = Path(root)
    profiles_path = Path(profiles_path)
    data = {"profiles": []}
    if profiles_path.exists():
        data = json.loads(profiles_path.read_text(encoding="utf-8"))
    data["profiles"] = [p for p in data["profiles"] if p.get("path") != str(root)]
    data["profiles"].append(profile)
    profiles_path.write_text(json.dumps(data, indent=1) + "\n", encoding="utf-8")

    names = {p.name.lower() for p in root.iterdir()} if root.is_dir() else set()
    if not (names & PROJECT_MARKERS):
        marker = {"schema": "fis.folder_profile/1.0",
                  "profiled_at": dt.datetime.now().isoformat(timespec="seconds"),
                  "folder_role": profile.get("folder_role", "general"),
                  "answers": answers, "evidence": evidence}
        (root / MARKER).write_text(json.dumps(marker, indent=1) + "\n", encoding="utf-8")
```

```python
sys.path.insert(0, str(Path(__file__).resolve().parent))          # profile_core
sys.path.insert(0, str(REPO))                                     # hub package

from PySide6.QtWidgets import (QApplication, QWizard, QWizardPage, QVBoxLayout,
                               QLabel, QLineEdit, QMessageBox)     # noqa: E402
import profile_core as pc                                          # noqa: E402


class QuestionPage(QWizardPage):
    def __init__(self, q: dict, suggestion: dict | None, parent=None):
        super().__init__(parent)
        self.qid = q["id"]
        self.setTitle(q["question"])
        lay = QVBoxLayout(self)
        self.edit = QLineEdit()
        if suggestion:
            val = suggestion.get("value", "")
            self.edit.setText(", ".join(val) if isinstance(val, list) else str(val))
            lay.addWidget(QLabel(f"suggested ({suggestion['source']}, "
                                 f"{suggestion['confidence']:.0%}) — edit if wrong"))
        lay.addWidget(self.edit)


class ProfileWizard(QWizard):
    def __init__(self, root: Path):
        super().__init__()
        self.root = root
        self.setWindowTitle(f"Profile this folder — {root.name}")
        self.quiz = pc.load_questionnaire(REPO / "config/rules" / pc.QUESTIONNAIRE)
        self.evidence = pc.scan_evidence(root)
        self.sugg = pc.suggest_answers(self.quiz, self.evidence)
        self.pages: list[QuestionPage] = []
        for q in sorted(self.quiz["core_questions"], key=lambda x: x["order"]):
            page = QuestionPage(q, self.sugg.get(q["id"]))
            self.pages.append(page)
            self.addPage(page)

    def accept(self):  # Finish — the ONLY write
        answers = {p.qid: p.edit.text().strip() for p in self.pages if p.edit.text().strip()}
        profile = pc.build_profile(self.root, answers, self.quiz)
        pc.write_profile(self.root, profile, REPO / "config" / "folder_profiles.json",
                         answers, self.evidence)
        QMessageBox.information(self, "Profiled",
                                f"{self.root} is now profiled as '{profile['folder_role']}'.")
        super().accept()


def main() -> int:
    folder = sys.argv[1] if len(sys.argv) > 1 else None
    app = QApplication(sys.argv)
    if not folder:
        from PySide6.QtWidgets import QFileDialog
        folder = QFileDialog.getExistingDirectory(None, "Pick a folder to profile")
        if not folder:
            return 0
    w = ProfileWizard(Path(folder))
    w.show()
    return app.exec()


if __name__ == "__main__":
    raise SystemExit(main())
```
